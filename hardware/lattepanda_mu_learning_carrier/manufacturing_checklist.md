# 制造前检查与学习清单

这份清单用于学习如何把“完整原理图和 PCB”推进到真正的生产资料。当前
没有完成的项目不得擅自勾选。

## 1. 设计输入

- [ ] 锁定计算模组的 N100/N305、内存和 eMMC 具体 SKU；
- [ ] 锁定 BIOS 版本并逐一核对 DDI、USB 和 PCIe HSIO 复用；
- [ ] 明确输入方式：12–20 V DC Jack、15 V USB-PD，或两者都保留；
- [ ] 形成最大/典型/待机功耗预算与各电源轨电流预算；
- [ ] 核对 3.3 V GPIO 的绝对最大额定值，禁止直接接 5 V 逻辑；
- [ ] 锁定所有外部连接器的机械型号和配套线缆。

## 2. 原理图

- [ ] 用 KiCad 9 的当前稳定版重跑 ERC，并逐项解释豁免；
- [ ] 按 260-pin 引脚表核对 VIN、VBAT、GND 和所有保留脚；
- [ ] 检查电源上电、掉电、反灌、软启动和过流路径；
- [ ] 核对 CH224K 的 15 V PD 档位配置与 Type-C CC 网络；
- [ ] 核对 SY8253ADC 的电感、反馈分压、输出电容和环路要求；
- [ ] 核对 USB/HDMI/PCIe/RJ45 接口处 ESD 器件的工作电压与结电容；
- [ ] 检查 PCIe 参考时钟、PERST#、CLKREQ#、WAKE# 和 AC 耦合位置；
- [ ] 检查所有外部控制信号的默认上拉/下拉和掉电状态；
- [ ] 生成 BOM，并为每个关键器件记录制造商料号和至少一个替代料。

## 3. PCB

- [ ] 与板厂确认四层叠层，不只按“1.6 mm 四层板”下单；
- [ ] 根据实际介质厚度、铜厚和介电常数计算单端/差分阻抗；
- [ ] 约束 USB、HDMI、PCIe 和以太网差分对的阻抗、长度和对内偏差；
- [ ] 检查每一次换层的参考平面连续性和就近回流过孔；
- [ ] 禁止高速线跨平面分割、开槽或电源岛边缘；
- [ ] 检查 DC 输入、模组 VIN 和 PCIe 12 V 大电流铜宽及温升；
- [ ] 检查开关电源热回路面积、SW 节点铜皮和反馈采样路径；
- [ ] 检查 Type-C、HDMI、USB、RJ45 的 ESD 器件是否紧靠连接器；
- [ ] 重灌所有铜皮，运行 DRC，并人工查看每一个未连接网络；
- [ ] 检查器件庭院、连接器外壳、模组散热器和机箱干涉；
- [ ] 检查螺丝孔、板边、V-cut/铣槽和铜到板边距离。

## 4. 生产资料

- [ ] 导出并用独立 Gerber 查看器复核所有铜层、阻焊、丝印和板框；
- [ ] 核对 Excellon 钻孔单位、PTH/NPTH 分类和槽孔；
- [ ] 生成 BOM、CPL/XY、装配图、坐标原点和顶底面说明；
- [ ] 对细间距器件检查钢网开口和散热焊盘分窗；
- [ ] 冻结 Git 提交、KiCad 版本、输出文件哈希和板厂工艺单；
- [ ] 在正式数量前只做小批样板。

## 5. 首板上电

- [ ] 不装模组，限流电源检查输入保护和各待机电源轨；
- [ ] 检查 3.3 V、5 V、12 V、VBAT 的阻值和静态电流；
- [ ] 装模组后继续限流，记录各阶段电流与电源时序；
- [ ] 先验证电源键、复位键、状态灯和串口，再接高速外设；
- [ ] 逐项验证 HDMI、USB、网口、M.2 和 PCIe；
- [ ] 做冷启动、热启动、掉电、睡眠、唤醒和异常输入测试；
- [ ] 记录所有改板线、替换料和测量波形，再进入下一版。
