\section*{零基础机器概念与实体载板验收}

\begin{itemize}
  \item 能解释 bit、byte、KiB、MiB、十六进制分别表示什么，并说明地址数值

  \item 能用“取指、译码、执行、提交”描述 CPU 的基本职责，并区分寄存器、

  \item 能完整复述“输入电源、时钟、复位、Flash 取指、DRAM 初始化、引导器、

  \item 能区分电压、电流、电阻和功率，写出 \(V=IR\)、\(P=VI\)，并说明

  \item 能区分器件引脚、原理图导线、同名网络、PCB 走线、连接器和总线协议；
  \item 能说明原理图符号、PCB footprint 和实物封装各回答什么问题，以及
        pin-to-pad 映射错误为什么能让正确原理图变成错误成品；
  \item 能从 J/U/Q/D/F/L/R/C/SW/TP 位号前缀辨认连接器、IC、MOSFET、
        二极管、保险丝、电感、电阻、电容、开关与测试点；

        省略；
  \item 能说明 CPU/SoC、计算模块、载板、主板和扩展设备的层级，并准确界定
        “Mu 模块加载板”案例在哪个产品边界上完整；
  \item 能复述 DFR1142 V2 的 10 个原理图页、305 个 footprint、407 个 net、
        3961 段走线、1307 个过孔、\(146\mathrm{mm}\times102\mathrm{mm}\)
        板框与约 1.6062 mm 四层叠层分别证明什么；
  \item 能从 J17 经 F6、D29、D15--D17 追到 VDC，并区分保险丝、TVS 和
        肖特基二极管各自处理的故障；
  \item 能从 J18 CC1/CC2、U14 CH224K、R43、15 V VBUS、D18--D20 追到
        VDC，并解释“PD 协商”和“降压转换”为什么不是同一动作；
  \item 能从 J19 的 +VBAT、D30--D32、USB2 Port 8、UPS 状态和控制脚说明
        Smart UPS 接口为什么不只是两根供电线；
  \item 能解释三路 diode-OR 怎样减少输入反灌，以及 \(I V_f\) 损耗、并联
        不均流与温升为什么仍需验证；
  \item 能从 VDC 分别追到 Mu VIN、Q7 \code{+12VA}、U15 \code{+5V}、
        U16 \code{+3V3} 和 U17 \code{+3V3\_ROM}；
  \item 能说明 SY8253 降压中的开关、电感、输出电容、反馈与 EN 如何形成能量
        回路和控制回路，为什么 SW 与 FB 的 PCB 布局很重要；
  \item 能解释 Mu pins 250--260 为什么并联 11 个 VIN 触点，为什么多个 GND
        同时降低功率阻抗并为高速对提供返回；
  \item 能逐项给出 HSIO0/1/2/3/6/8--11 在本载板上的 USB、M.2、GbE 和

        从铜线到内核服务的完整链；
  \item 能从 Mu DDI\_B 四对 TMDS、DDC SCL/SDA、HPD、5 V、GND 追到 HDMI

  \item 能解释 I2C 开漏、上拉、起始、地址、应答和停止；确认 I2C 地址不是

  \item 能解释 UART 的起始/数据/停止位、TX/RX 方向和共同地，说明 3.3 V

  \item 能解释 SPI CLK/CS/IO0--IO3 与 \code{BIOS\_SEL} 的作用，并说明

  \item 能区分风扇 5 V 能量、PWM 控制、TACH 反馈和 NTC 温度输入，说明方向
        与电平为什么都要核对；
  \item 能说明四层板、连续 GND 平面、阻抗、回流过孔、去耦位置和连接器侧
        ESD 之间的关系，避免把“DRC 无报错”等同于“高速一定工作”；
  \item 能区分原理图、PCB 文件、ERC/DRC、制造资料和成品测量各自能证明与
        不能证明的边界；
  \item 能对照说明 QEMU 自研 ROM/ATA PIO/COM1/PIC/PIT/i8042 与实体
        UEFI/NVMe或eMMC/GOP/APIC/USB HID 的平台差异；
  \item 能列出实体适配需要的 UEFI 入口、Memory Map、ACPI、PCIe 枚举、
        控制台、存储和输入驱动，且不声称当前 STUOS 已经能在 Mu 上裸机启动；
  \item 能沿全机总览、阶段路线、Port I/O、启动与内存、中断、键盘到 Shell、
        存储持久化七张图，分别把电气连接、硬件事务、控制转移和数据所有权

  \item 能根据图例区分 PCB 实线、虚拟平台连接、软件控制流和数据/所有权流，
        确认一条线两端都有明确生产者与消费者，跨层连接没有被箭头装饰替代；
  \item 能核对模块正反面方向、pin 1/2/259/260、缺口和 260 个触点，并说明
