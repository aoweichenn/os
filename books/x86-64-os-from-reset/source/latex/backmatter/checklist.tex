\chapter*{能力与验收清单}
\addcontentsline{toc}{chapter}{能力与验收清单}

\section*{v0.7 完成后的知识验收}

\begin{itemize}
  \item CPU 从物理地址 \code{0xFFFFFFF0} 取第一条指令的复位状态；
  \item 128 KiB ROM 的文件偏移怎样对应高端物理地址；
  \item 近跳转保留复位时 CS 隐藏基址的机制；
  \item NASM、LLD、objcopy 各自承担的转换阶段；
  \item COM1 的 DLAB、除数、8N1、FIFO 和线路状态位；
  \item 串口轮询采用有限预算所建立的失败边界；
  \item ROM 审计、单元、随机和 QEMU 测试各自覆盖的错误类别。
  \item ATA 主通道端口、LBA28 字段和 BSY/DRQ/ERR/DF 状态；
  \item Stage 1 描述符、两级校验与加载范围承担的不同边界；
  \item 远控制转移重载 CS 与 Stage 1 重新建立 DS 的原因；
  \item IDE 超时、设备错误、头损坏和负载损坏的可区分证据。
  \item 32 个 2 MiB 大页如何形成低 64 MiB 恒等映射；
  \item Kernel 描述符 CRC、精确文件 CRC 与扇区零填充的不同边界；
  \item IEEE CRC32 反射多项式和逐位更新过程；
  \item ELF64 文件头、程序头与 \code{PT\_LOAD} 的职责区别；
  \item 两遍装载为何能在失败前保持目标区无副作用；
  \item BSS 的历史来源以及 \code{p\_memsz-p\_filesz} 必须清零的原因；
  \item W\^X、段间不重叠、恒等装载窗口和可执行入口检查；
  \item BootInfo v2 十三个固定宽度字段及 RDI、RSP 的 ABI 契约；
  \item 内核独立串口、BSS 探针和 CR3 读回分别证明什么；
  \item 五种 Kernel 失败路径怎样由真实 QEMU 故障注入到达。
  \item 长模式弱化分段后仍需要 GDT、代码段和 TSS 的历史与硬件原因；
  \item 五槽 GDT 的索引、选择子、代码/数据属性和双槽 TSS 描述符；
  \item GDTR/IDTR 的 inclusive limit 为什么分别是 39 和 4095；
  \item RSP0 与 IST1--IST3 的用途，以及三个 16 KiB 专用栈的故障边界；
  \item \code{LGDT} 后必须远控制转移刷新 CS 隐藏缓存的原因；
  \item 32 个架构异常中哪些由 CPU 压入错误码；
  \item 统一 160 字节异常帧的寄存器、向量、错误码和 CPU 返回字段顺序；
  \item 异常公共桩为什么执行 CLD、重新对齐 RSP 并使用 IRETQ；
  \item fault、trap、abort 的 RIP 与恢复语义差异；
  \item INT3、UD2 和页故障三条 QEMU 路径分别证明什么；
  \item 页故障错误码零与 CR2=\code{0x04000000} 的逐位含义；
  \item panic 为什么禁止动态分配、锁、递归日志和普通返回。
  \item \code{fw\_cfg} selector/data 端口、文件目录大端序和
        \code{etc/e820} 小端条目的边界；
  \item 20 字节平台项为什么扩展为 24 字节 ABI，Stage 1 排序后内核为何仍验证；
  \item 描述字节、可用字节与低 64 MiB 受管可用字节的区别；
  \item 2-bit 页帧的 unavailable、free、allocated、reserved 状态迁移；
  \item 启动保留为什么先检查完整范围再提交，避免部分状态；
  \item 48 位 canonical 地址和 PML4、PDPT、PD、PT 四组 9 位索引；
  \item present、RW、US、PS、物理地址和 NX 的页表项位布局；
  \item text、rodata、data/BSS、heap、零页和 guard 的权限差异；
  \item EFER.NXE 与 CR0.WP 分别解决取指和 supervisor 写保护；
  \item 错误码 3 与 CR2=\code{0xFFFF800000100000} 为什么证明写保护执行；
  \item 高半区 64 KiB 单调堆的对齐、溢出、容量和无释放边界；
  \item 单元、集成、固定种子模型对照和 QEMU 执行各自证明什么。
  \item PIC、I/O APIC、本地 APIC 和 RFLAGS.IF 分别处于哪一层；
  \item 为什么没有 BIOS 时必须显式处理 \code{IA32\_APIC\_BASE[11]}；
  \item 8259A ICW1--ICW4、主从级联、IMR、ISR 与 EOI 的完整状态机；
  \item IRQ7 与 IRQ15 的虚假中断为什么采用不同 EOI 规则；
  \item 向量 32--47 的硬件桩怎样复用 160 字节帧而不复用异常策略；
  \item PIT 模式 2、1193182 Hz 输入、16 位除数和单调毫秒的量化关系；
  \item i8042 输入/输出缓冲、配置 byte、\code{F4}/\code{FA} 握手；
  \item 扫描码集合 1 的 make、break、\code{E0} 前缀为何不是 ASCII；
  \item 内核 ATA PIO 自检为什么保持 \code{nIEN}，又证明了什么所有权；
  \item 为什么 IRQ0 不逐 tick 打日志，宿主时间与来宾时间有何不同；
  \item QMP \code{sendkey} 为什么是硬件输入而不是来宾驱动替代；
  \item 46 项 CTest 如何分别覆盖模型、组合、ELF ABI 与整机异步事件。
\end{itemize}
