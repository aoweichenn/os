\chapter{电压怎样变成逻辑和状态}

一根导线上的电压先被输入电路判断为高或低，逻辑门再把这些状态组合成新的
结果。组合结果本身不会记住过去；加入反馈和时钟以后，触发器才会在指定边沿
保存一位状态。本章沿着同一条信号路径，从电源和引脚一直走到寄存器与状态机。
