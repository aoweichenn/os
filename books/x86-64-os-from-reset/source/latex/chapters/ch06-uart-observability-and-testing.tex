\begin{keyidea}
串口输出不是装饰性日志，而是 CPU 与异步设备共同推进的硬件协议。测试必须
把阶段、时间、正常完成和失败原因编码成有界证据，并用独立 oracle 证明看到
的现象确实来自生产路径。
\end{keyidea}
