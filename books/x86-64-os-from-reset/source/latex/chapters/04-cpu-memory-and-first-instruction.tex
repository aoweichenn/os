\chapter{CPU 怎样读到第一条指令}

按下电源键以后，CPU 还没有可以调用的操作系统。复位电路先把处理器保持在
已知状态，时钟稳定后再释放复位；CPU 随即把一个固定地址放到平台互连上，
读回第一批指令字节。本章沿这次读取认识 CPU、RAM、ROM、总线、地址译码和
设备。
