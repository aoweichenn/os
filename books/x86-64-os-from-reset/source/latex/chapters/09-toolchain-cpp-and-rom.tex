\chapter{把源码变成一块启动 ROM}

CPU 不能读取 \code{.cpp} 文件。编译器先生成指令和未决符号，汇编器与链接器
再决定每段代码的最终地址，镜像工具最后把复位跳转放进 ROM 末尾的固定 16
字节。本章从一份短源码一直跟到 ROM 十六进制内容，并说明裸机 C++ 还缺哪些
运行时支持。
