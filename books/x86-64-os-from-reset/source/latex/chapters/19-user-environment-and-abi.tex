\chapter{用户程序怎样使用系统服务}

用户程序不能直接调用内核中的 C++ 函数，它们通过稳定的系统调用号、寄存器
约定和返回值与内核通信。最小运行时把这些约定包装成可用接口，Shell、
devfs 和 procfs 再把进程、设备和系统状态组织成用户能够操作的环境。
