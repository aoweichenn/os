# 教材知识顺序与素材边界

本文件写给书稿维护者，用来记录章节依赖和素材归属。它不是正文模板。文字
编辑方法见 `EDITORIAL.md`。教材以 STUOS v2.0 的实现、构建产物和运行结果
为准；调整书稿结构不得改变 Kernel、ABI、rootfs 盘面或项目版本。

## 为什么采用 31 章主线和 4 章硬件附录

上一版的二十个章节入口已经比旧结构自然，但内部仍有六类超大正文：内存与
异常、调度与系统调用、对象与 VFS、进程与虚拟内存、存储、等待与终端。
其中最长文件超过两千行。读者在“内存与异常”一章里连续遇到 GDT、IDT、
buddy、页表、KVA、动态栈、堆和类型缓存，目录却无法跳到这些机制。

本版按可独立实验的边界组织成 31 章：

- 异常、物理页、页表、KVA/栈、堆分别成章；
- 调度与系统调用分开；
- KernelObject/FileTable 与 VFS/路径分开；
- PID 1/exec 与 VMA/fork 分开；
- 盘面、rootfs、IRQ/writeback、journal 分开；
- WaitQueue/pipe/futex/time 与 signal/TTY/job control 分开。

前四章构成从物理状态到第一条指令的完整地基。正文保留 bit、byte、补码、
端序、地址、KCL、RC、输入输出引脚、推挽/开漏/三态、组合逻辑、锁存器、
D 触发器、setup/hold、基础 CDC、寄存器、教学指令集、逐周期执行、总线
事务、存储器、地址译码与 ROM 取指。测量误差、器件选型、开关电源、静态
时序例外、复杂 CDC、PCB、DRAM 训练和实体整机资料进入四个硬件深化附录。
内容按“必须理解、深入理解、项目连接、动手实验、暂时跳过”标记阅读层次，
不再用几页摘要代替知识地基。

## 八部分各做什么

| 部分 | 章节 | 读者遇到的问题 | 主要机制 |
|---|---:|---|---|
| 物理世界到计算机 | 1–4 | 0 和 1 怎样成为可取指的机器 | bit、byte、电压、逻辑门、寄存器、CPU、RAM、ROM |
| 读懂 x86 复位现场 | 5–8 | OS 从哪里接手，x86 指令怎样改变状态 | 软件层次、Intel 汇编、复位历史、平台 I/O |
| 生成字节并进入内核 | 9–11 | 源码怎样成为 ROM 并切入 64 位 | 工具链、UART、ATA、ELF、A20、GDT、页表 |
| 内核接管机器 | 12–17 | 异常、地址和设备怎样进入内核 | GDT/TSS/IDT、buddy、分页、KVA、heap、IRQ、Ring 3 |
| 程序共享 CPU 和对象 | 18–23 | 线程、fd、路径和地址空间怎样协作 | 调度、SYSCALL、FileTable、VFS、PID 1、exec、VMA、fork |
| 数据持久化 | 24–27 | 一个字节怎样跨重启保留 | inode、rootfs、ATA IRQ、writeback、ordered journal |
| 等待、通信和用户环境 | 28–30 | 程序怎样睡眠、收信号并受终端控制 | pipe、futex、time、signal、TTY、Shell、devfs、procfs |

## 前四章的阅读层次

前四章直接输入 `source/latex/foundations/` 中的完整基础材料，沿五步推进：

1. bit、byte、十六进制、补码、端序、地址和 ROM 文件偏移；
2. 电压参考、闭合回路、引脚输出结构、电源、时钟和复位；
3. 逻辑门、组合逻辑、锁存器、D 触发器、寄存器和状态机；
4. 教学指令集、逐周期 CPU、RAM、ROM、互连和取指；
5. 把教学模型映射到 x86 复位地址与真实项目产物。

每章仍保持 4–6 个编号主节，细部用 topic 书签导航。正文保留理解下一层所需
的公式、波形、状态表、手算和推导；附录只接收不会阻断主线的仪器误差、
器件选型、静态时序例外、复杂 CDC、PCB、高速接口、DRAM 训练和实体整机
资料。`foundations/mainline/` 保留为简明素材来源，不再直接作为成书正文
入口。

## 系统机制怎样分章

章节边界按第一次可观察结果确定：

- 第 12 章止于异常可解码；
- 第 13 章止于物理页可分配和归还；
- 第 14 章止于地址可翻译并受权限保护；
- 第 15 章止于动态内核栈可建立和回收；
- 第 16 章止于不同大小对象可分配和释放；
- 第 18 章只讲调度现场，不提前讲 pipe；
- 第 20 章只讲对象和 fd，第 21 章再讲名字与挂载；
- 第 24–27 章分别以盘面、文件规模、设备完成、断电恢复为终点；
- 第 28 章讲等待原语，第 29 章讲终端策略，第 30 章只做用户态整合。

内部作者仍可检查历史、硬件事实、所有权、正常路径、失败路径、代码和测试，
但这些项目不能机械变成每章相同的七段正文。A20 沿地址回绕讲，UART 沿第一
个字符讲，fork 沿父子写入冲突讲，journal 沿断电位置讲。

## 源码走读和导航

- 一次正文代码清单只解释一个动作；通常控制在 5–40 行。
- ROM 完整源码仍保留仓库路径，但正文分别展示复位跳转、入口状态、UART
  初始化、字符串遍历和 THRE 超时。
- 每章开头用 `\chapterroute` 给出 4–6 个阅读节点。
- `\section` 进入纸面目录；`\topic` 不编号，但进入 PDF 书签并显示在奇数页
  页眉。手机阅读可以跳到 GDT、buddy、COW 或 replay。
- 生产源码行数属于维护统计，不进入教材正文。

## 字体和排版

- 正文、章、节、路线框、页眉和代码统一使用 Maple Mono NF CN。
- 标题靠字号、粗体、颜色与上下留白建立层级；代码靠等宽排版、底色和边框
  与正文区分。
- 每章 4–6 个编号主节；不得用大量编号二级标题切碎叙事。
- 所有语义表格使用实线网格环境；每行、每列和外框都有实线。
- 插图构建后必须渲染检查节点重叠、箭头穿字、标签压线和手机可读性。

## 全仓资料怎样进入书稿

- `docs/background_knowledge.md` 和 `docs/learning/background/` 提供历史与
  前置概念；
- `docs/learning/00-*.md` 与 `01`–`27` 分册提供真实演进与实验事实；
- `docs/architecture.md`、`docs/modules/` 与 ADR 提供当前职责和取舍；
- `docs/hardware/`、器件资料和矢量图提供寄存器、引脚与电气事实；
- `docs/testing.md`、`debugging.md`、`logging.md` 提供反例和故障定位；
- Intel SDM、ELF 规范与设备资料用于最后一轮技术审校。

正文按因果依赖重组，不按文件逐段复制。书末
`learning-integration-map.tex` 保留从原学习分册反查章节的入口。

## 构建门禁

1. 31 个主线章与 4 个硬件附录的所有 `\input` 必须可达；
2. 每章必须有 4–6 个编号主节；
3. 图像只接受 TikZ/CircuitikZ 或矢量 PDF；
4. 表格只接受三种 `osgrid*` 实线网格环境；
5. XeLaTeX 不得有未定义引用、正文越界或致命错误；
6. 标题、正文和代码均使用 Maple Mono，并以字号、字重、颜色和边框区分职责；
7. 核心代码统计只计生产 `.asm`、`.cpp`、`.hpp`，且不进入正文；
8. 本轮只修改教材；Kernel、ABI、盘面和网站不得变化；
9. 源 PDF 与手机导出件必须具有相同 SHA-256。
