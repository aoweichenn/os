# 教材知识顺序与素材边界

本文件写给书稿维护者，用来记录章节依赖和素材归属。它不是正文模板。具体的
文字编辑方法见 `EDITORIAL.md`。教材使用 STUOS v2.0 的实际代码与运行结果，
结构调整不改变 Kernel、ABI、rootfs 盘面或项目版本。

## 为什么从六部十六章扩展为七部二十章

六部十六章已经解决了高级机制拥挤问题，却仍把电压、晶体管、逻辑门、CPU、
ROM、引脚、总线、地址和操作系统责任放在第一章。对熟悉计算机的人这是复习，
对真正零基础读者却是十余个尚未建立的抽象同时出现。

本版新增四章零基础预备：

1. 量、单位、进制、编码、误差与证据；
2. 电压、电流、电阻、电容、半导体元件与原理图；
3. 逻辑门、加法器、触发器、时钟、时序与状态机；
4. CPU、存储器、引脚、总线、地址译码与完整启动条件。

原十六章保持机制边界和内部阅读顺序，整体成为第 5--20 章。这样读者第一次
看到 ROM 时，已经理解非易失存储为何能响应取指；第一次看到 CPU 接线时，
已经会区分电源、地、时钟、复位、地址、数据和完成信号。

## 前四章不是“术语预览”，而是四个可独立验收的基础系统

前四章采用“主叙事 + `foundations/expanded/` 第二深度层”的组织方式。主叙事
保证第一次阅读不断线；第二深度层把容易被一句话带过的公式、器件、电路和状态机
展开成可计算、可画图、可测量、可证伪的教材单元。

| 章 | 第一条知识链 | 第二条知识链 | 第三条知识链 | 章末综合能力 |
|---:|---|---|---|---|
| 1 | SI 单位、量纲、科学计数、误差与仪器负载 | 二进制算术、补码、进位/溢出、端序、对齐与半开区间 | 帧、奇偶校验、CRC、串并行、延迟/吞吐/并发与计算史因果 | 把任何规格还原为对象、量、单位、编码、边界和证据 |
| 2 | 电荷、电势、参考地、真实电源、KCL、戴维南、阻抗 | 电阻/电容/二极管/BJT/MOSFET/电感/稳压/时钟器件及数据手册 | PCB 叠层、回流、差分、去耦、SPI Flash、ESD、bring-up 与测量安全 | 从电源输入画到芯片引脚，并计算与验证每个关键节点 |
| 3 | 逻辑阈值、噪声裕量、推挽/开漏/三态与电平转换 | 布尔代数、卡诺图、加法器、MUX、译码/编码和移位网络 | latch、DFF、setup/hold、skew/jitter、CDC、消抖、复位域与 FSM | 从晶体管电平一路推导到可同步提交的有限状态机 |
| 4 | ISA、微架构、寄存器文件、教学编码、数据通路与提交 | 总线通道、valid/ready、仲裁、byte enable、MMIO 与 Port I/O | Cache/AMAT、SRAM/DRAM/Flash、地址译码、x86 reset 与 ROM 映射 | 从按下电源追到 reset vector 的字节被取回、译码并提交 |

这四章不使用“现实中更复杂”作为省略理由。若真实系统比教学模型多出一层，
正文必须至少指出新增对象、接口和失败模式。例如：理想电源之后补内阻与瞬态；
逻辑门之后补阈值与传播延迟；同步电路之后补亚稳态；教学总线之后补握手、等待、
错误与仲裁；“ROM”之后补现代 Flash 的擦写粒度、写保护与掉电风险。

## 零基础内容的作者检查表

第一次出现物理或数字概念时，尽量形成九层：

1. 可观察对象：读者能在图、实物或测量中指出它；
2. 量与单位：给出符号、单位、范围和参考点；
3. 元件或结构：解释内部最低必要组成，不用新黑盒替换旧黑盒；
4. 图形表示：给出原理图、引脚图、逻辑图、时序图或结构图；
5. 公式推导：说明公式来自什么守恒或定义，并检查量纲；
6. 完整数值算例：代入单位、计算数量级、讨论容差；
7. 历史因果：当时的问题、限制、方案和今天的痕迹；
8. 失败反例：反接、超范围、时序违反、地址误译或所有权错误；
9. 后续连接：明确它将在 ROM、CPU、Kernel 或用户机制中怎样再次出现。

一张图必须说明其证据边界。逻辑图不证明电气时序；原理图不证明 PCB 已正确
布线；QEMU 事务图不证明实体板供电和信号完整性；实物照片也不证明内部协议。

## 系统机制的作者检查表

下面八项只用于检查是否漏掉关键内容，不得依次变成每章相同的八段正文：

1. 历史动机；
2. 机器或 ABI 精确定义；
3. 抽象与所有权边界；
4. 正常路径和唯一提交点；
5. 失败路径与回滚；
6. 汇编/C++/盘面实现走读；
7. 单元、集成、随机、产物和 QEMU 证据；
8. 当前 v2.0 限制与未来前置。

成文时由具体问题决定顺序。A20 从地址回绕展开，UART 从输出实验展开，页表
从地址手算展开，fork 从共享与隔离展开，journal 从断电状态展开。编辑过程
遵守 `EDITORIAL.md` 的三轮方法。

## 章节与正文排版

每章只保留 4--6 个编号主节，当前正文统一采用 5--6 个。主节必须覆盖一条
完整知识链，例如“物理内存图、页帧所有权与伙伴分配”，不能把一个寄存器、
一个字段或一个测试样例单独提升为主节。

主节内部使用连续叙述。需要提示局部转折时使用不编号的 `\topic` 段首主题，
并让解释正文紧随其后；不得重新引入 `\subsection` 或 `\subsubsection`，
也不得用几十个视觉小标题代替段落之间的因果连接。目录深度和编号深度都只到
`\section`，因此目录呈现二十章及其约百条主线，而不是机制索引。

## 全仓文档怎样融合

- `docs/learning/background/` 提供计算机、数据、工具链、内存、中断、进程和
  测试七条背景链。

- `docs/hardware/`、实体载板资料和矢量图提供寄存器、引脚、网络与电气事实。
- `docs/testing.md`、`debugging.md`、`logging.md` 提供反例和证据边界。
- `docs/releases/` 提供历史基线和 v2.0 冻结结果。

书稿不按文件逐段复制，而按因果依赖合并。书末
`learning-integration-map.tex` 保留逐文档反查入口。

## 编辑与构建门禁

1. 20 个章节入口和所有 `\input` 必须可达；
2. 插图优先使用 TikZ/CircuitikZ 或无损矢量 PDF；
3. 每个新增硬件图必须标注“概念图”还是“具体器件事实”；
4. XeLaTeX 构建不得有未定义引用、正文越界或致命错误；
5. 核心代码统计只计生产 `.asm`、`.cpp`、`.hpp`；
6. 本轮只修改教材；Kernel、ABI、盘面和网站不得随教材重写而变化；
7. 所有语义表格必须使用 `osgridtabular`、`osgridtabularx` 或
   `osgridlongtable`，外框、每列和每行都使用连续实线；原始 `tabular`、
   `tabularx`、`longtable` 环境和缺少 `\hline` 的表格行由输入检查拒绝；
8. 每章必须保持 4--6 个编号主节，正文章节不得使用编号二级或三级节；
9. 源 PDF 与手机导出件必须具有相同 SHA-256。
