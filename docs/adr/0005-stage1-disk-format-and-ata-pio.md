# ADR 0005：自描述 Stage 1 格式与单扇区 ATA PIO

状态：已接受
日期：2026-07-24

## 背景

v0.2 要在不借助 BIOS 磁盘服务和第三方引导器的情况下，从 IDE 主盘取得下一
阶段代码。裸扇区跳转无法证明负载长度、目的地址、入口或完整性，也无法为后续
格式演进保留版本边界。

## 决策

1. LBA 0 保存 512 字节自描述头，负载从显式 LBA 开始。
2. 所有字段使用小端固定宽度编码，固件按偏移解析。
3. 格式包含 magic、版本、头长度、加载段、入口、扇区数、标志、负载 LBA、
   负载校验和描述符校验。
4. 描述符使用整扇区 16 位字零和，负载使用独立 16 位字和。
5. 固件只接受 1 到 64 个扇区、LBA28 范围和 `[0x8000, 0x9FC00)` 加载窗口。
6. ATA PIO 每条命令只读一个扇区，逐扇区推进 LBA 和 ES:DI。
7. 所有状态等待有界，并把永久忙与 ERR/DF 分成不同失败结果。
8. 使用远返回装载描述符提供的 CS:IP，不依赖复位后的 CS 隐藏缓存。

## 原因

单扇区命令牺牲少量吞吐量，换来精确的失败扇区和更简单的状态机。自描述头把
镜像生成、宿主审计和目标解析连接到同一契约；两级校验能区分元数据损坏与负载
损坏。固定加载窗口避开描述符缓冲区、低端栈和传统内存上界。

## 后果

- v0.3 可以直接从已验证 Stage 1 入口开始实现模式转换。
- 当前校验不是密码学摘要，不提供对抗恶意修改的安全启动能力。
- 当前磁盘大小和最大扇区数属于 v0.2 格式约束，扩展时必须提升版本。
- 生产路径和故障注入路径共享状态机，测试宏不得进入格式或公共接口。
