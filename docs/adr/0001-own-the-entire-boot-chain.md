# ADR 0001：自研完整启动链

- 状态：已接受
- 日期：2026-07-23

## 背景

项目的目标是通过实现操作系统理解各层机制。如果依赖现成固件或启动器，CPU 复位、磁盘加载、模式切换和 ELF64 加载会被隐藏。

## 决策

QEMU 只用于模拟硬件。项目从 x86-64 复位向量开始，自行实现 ROM 固件、引导阶段、处理器模式切换、ELF64 内核加载和 C++20 运行时。

不使用 SeaBIOS、OVMF、GRUB、Limine、Multiboot 或 QEMU `-kernel` 代替启动链。

## 影响

- 学习范围更完整，启动过程中的每个状态都可解释。
- 初期开发成本和调试难度更高。
- 必须尽早建立串口日志、GDB 调试和自动化系统测试。
