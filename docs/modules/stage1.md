# Stage 1 模块

## 职责

`stage1` 是由自研 ROM 从磁盘装入 RAM 的第一段代码。当前职责包括：

- 以 NASM Intel 语法生成位置约定明确的 16 位平坦二进制。
- 被固件加载到描述符声明的实模式段，当前为 `0x0800:0x0000`。
- 入口重新以 CS 建立 DS，不继承 ROM 的常量寻址假设。
- 使用已经初始化的 COM1 独立输出 `[OS][STAGE1] ENTERED`。
- 加载基址为零的平坦 GDT，设置 `CR0.PE` 并远跳进入 32 位保护模式。
- 保护模式栈顶使用物理地址 `0x7000`，与 `0x8000` 起始的 Stage 1 负载区分离。
- 通过端口 `0x92` 打开 A20，并用 1 MiB 边界别名测试验证后恢复原值。
- 在 `0x10000..0x12FFF` 建立并自检 PML4、PDPT 和 PD，映射首个 2 MiB。
- 依次启用 PAE、LME 和分页，回读控制状态后远跳到 64 位代码段。
- 使用独立的 64 位 COM1 发送路径输出 `[OS][STAGE1] LONG_MODE`。

## 磁盘格式

LBA 0 是 512 字节描述符，LBA 1 开始保存按扇区补零的负载。头部前 28 字节：

| 偏移 | 宽度 | 字段 |
| --- | --- | --- |
| `0x00` | 8 | magic `OSSTAGE1` |
| `0x08` | 2 | 版本 |
| `0x0A` | 2 | 头长度 |
| `0x0C` | 2 | 加载段 |
| `0x0E` | 2 | 入口偏移 |
| `0x10` | 2 | 负载扇区数 |
| `0x12` | 2 | 标志 |
| `0x14` | 4 | 负载 LBA |
| `0x18` | 2 | 负载 16 位字和 |
| `0x1A` | 2 | 描述符校验字 |

描述符全部 256 个小端 16 位字相加后必须为零。负载校验字段等于所有补零后
负载字的模 `2^16` 和。校验用于发现变化，范围检查用于阻止越界，两者不能
互相替代。

## 交接契约

固件跳转前保证中断关闭、方向标志清零、SS 为零、SP 为 `0x7000`，Stage 1
负载已校验。CS:IP 来自描述符，DS 仍为零，因此入口必须先执行 `push cs` /
`pop ds` 才能用自身相对偏移访问常量。

v0.4 将在本模块中继续实现 ELF64 校验、内核装载和 BootInfo 交接。
