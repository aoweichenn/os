## 已知限制

- 空 ROM 不包含可执行固件，QEMU 以 `-S` 暂停 CPU。
- 尚未生成可启动镜像或串口输出。
- 尚未引入 NASM 源文件；NASM 在工具链基线中完成检查。
- CI 结果以远程 GitHub Actions 的实际运行为准。
