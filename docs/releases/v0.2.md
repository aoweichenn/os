# v0.2 固件加载

发布日期：2026-07-24

## 目标

证明自研 ROM 能直接驱动 IDE ATA PIO，从磁盘读取、验证并执行自研 Stage 1，
不使用 BIOS 磁盘中断、第三方引导器或 QEMU `-kernel`。

## 实现

- 512 字节自描述 Stage 1 头和固定宽度小端字段。
- 描述符整扇区校验、负载校验、LBA28 和 RAM 加载范围验证。
- IDE 主通道、主盘、`READ SECTORS` 单扇区 PIO 状态机。
- BSY、DRQ、ERR、DF 分支和 `0xFFFF` 次有界轮询。
- Stage 1 加载到 `0x0800:0x0000`。
- 通过远返回重载 CS:IP，Stage 1 独立建立 DS 并输出进入标记。
- Python 标准库镜像编码、审计和损坏样例生成。

## 测试

本阶段完整回归共有 19 项 CTest。新增证据包括：

- Stage 1 格式正常审计和损坏描述符拒绝。
- 格式编码、截断、magic、LBA、加载范围和负载损坏单元测试。
- 256 组有效随机负载往返与 256 组越界 LBA 拒绝。
- QEMU 真实加载成功。
- QEMU IDE 永久忙、设备 ERR、描述符损坏和负载损坏失败路径。

真实目标代码现为 4 个文件、635 行非空非纯注释代码，其中 C++ 94 行、NASM
汇编 541 行。统计排除测试、工具、构建描述、书稿和网站。

成功串口协议：

```text
[OS][FIRMWARE] RESET
[OS][FIRMWARE] SERIAL_READY
[OS][FIRMWARE] STAGE1_HEADER_VALID
[OS][FIRMWARE] STAGE1_LOADED
[OS][STAGE1] ENTERED
```

## 已知边界

- 当前只使用主 IDE 通道的主盘和 LBA28。
- 每条 ATA 命令只读取一个扇区，不使用中断或 DMA。
- Stage 1 仍在 16 位实模式运行。
- 尚未启用 A20、GDT、保护模式、分页或长模式。
- 16 位字和只能发现常见损坏，不构成安全启动认证。
