# v1.15 发布记录：TTY、会话与作业控制

## 发布结论

v1.15 已把 PS/2 键盘、TTY 行规程、session/process group、停止/继续信号、
事件式 wait、`/dev/console` 与 Ring 3 Shell 作业表接成一条完整控制流。
QEMU 中的真实 `Ctrl-Z`、`fg`、`Ctrl-C`、`bg` 和 `command &` 均经过
i8042、IRQ1、TTY、组信号、scheduler 和 wait 事件，而不是宿主脚本修改
来宾内存或调用替代启动组件。

## 交付能力

- 1024 字节输入环、512 字节 canonical 编辑区、2048 字节同步输出环；
- 换行提交、退格、CR→LF、Ctrl-D EOF、Ctrl-C 中断和 Ctrl-Z 停止；
- 左右 Ctrl 的 PS/2 Set 1 make/break 状态与 C0 控制码翻译；
- PID/PGID/SID 独立身份、PID1 初始 session、fork 继承和同 session 组迁移；
- 单控制终端及 foreground PGID，后台读取返回专用错误且不消费输入；
- Process/Thread `Stopped` 状态、SIGSTOP/SIGTSTP 默认停止与 SIGCONT 继续；
- Stopped/Continued/Exited 三类父进程事件与 no-hang wait；
- `/dev/console` 字符设备 vnode、VFS open/stat/readdir/retain/close；
- Shell 有界 16 项作业表、`jobs`、`fg`、`bg`、尾部 `&` 和整条管线同 PGID；
- Shell/child 信号处置分离与前台终端交接/恢复；
- 进程组身份保留到 Zombie 收集，消除极短命令退出与父进程 `setpgid` 的竞态；
- `exec` 保留 Process/survivor pending，修复 Ctrl-Z 落入 fork/exec 窗口时
  已发生控制信号被新映像错误清空的竞态。

## ABI 冻结

系统调用 64--69 分别为 CreateSession、GetSession、SetProcessGroupFor、
GetTerminalInformation、SetTerminalForegroundGroup 和 WaitProcessEvent。
`TerminalInformation` 固定 24 字节，`ProcessWaitEventResult` 固定 56 字节。

wait flag 固定为 Exited=`1<<0`、Stopped=`1<<1`、Continued=`1<<2`、
NoHang=`1<<3`。新增错误为 -55、-56、-57；已有系统调用和错误编号不重排。

v1.15 构建图为 158 项 CTest：

- Terminal 单元测试覆盖 canonical 提交、退格、EOF、控制动作、前台权限、
  输出排空和精确字节守恒；
- JobControlManager 单元测试覆盖 PID1 session、fork 继承、组建立/加入、
  session leader 限制和最终归零；
- ConsoleDeviceFileSystem 单元测试覆盖字符 vnode、VFS 引用和目录枚举；
- 集成测试按 Stopped→Continued→Exited 顺序观察同一子进程，并证明停止期间
  不被 scheduler 选中；
- 固定种子随机测试执行 100000 次同 session PGID 迁移，每步验证 PID、
  SID、PGID 和统计；
- Shell 解析单元/随机测试覆盖尾部 `&` 和非法中间 `&`；
- QEMU functional smoke 逐键输入前台 `cat`，真实注入 Ctrl-Z，执行 jobs/fg，

输入统计使用
`submitted = read + buffered + editing + dropped + consumed`，控制字符不会被
伪装成普通用户数据。输出统计要求 queued=written+pending，最终 pending=0。

## 日志策略

IRQ1 和普通字符不逐次打印。低频语义边界打印作业等待、停止、后台启动和命令
完成 marker；Kernel 在阶段终态统一输出 TTY、scheduler、signal、process-tree
和 job-control 账本。QEMU runner 为每条串口行添加宿主单调到达时间，并为
每次按键事务设置 20 秒进度门限；失败时立即结束协议等待并回收 QEMU。

## 已知限制

- 当前只有一个控制终端和一个固定 `/dev/console`，没有通用 devfs；
- 只有 canonical 基线，没有 termios/raw mode、回显策略表或窗口尺寸；
- Shell 作业表固定 16 项，job id 只接受十进制且不支持 `%+`、`%-`；
- 后台写终端当前允许，后台读返回专用错误，尚未实现 SIGTTIN/SIGTTOU；
- 不支持 SIGHUP、孤儿进程组规则和完整 POSIX session 权限细节；
- 单 BSP 下用 irq-save 锁保护 TTY；SMP 锁序留给 v2.x。
