# v0.1 复位与串口

发布日期：2026-07-24

## 目标

证明 CPU 从项目自研 ROM 的复位向量执行，完成最早硬件初始化，并建立第一条
可自动回归的观测通道。

## 实现

- 128 KiB 高端 ROM：`0xFFFE0000..0xFFFFFFFF`。
- `0xFFFFFFF0` 复位向量：字节 `E9 0D F0`。
- `0xFFFFF000` 16 位 NASM Intel 语法入口。
- 显式 `CLI`、`CLD`、段寄存器和 `0x7000` 栈。
- COM1 115200、8N1、FIFO 和 modem control 初始化。
- THRE 有界轮询、字节发送和零结尾字符串发送。
- 正常与串口超时两份同源 ROM。
- NASM → LLD → llvm-objcopy 的可重复生成链。

## 测试

本阶段完整回归共有 12 项 CTest：

- C++ foundation 单元、集成与 10,000 组随机测试。
- freestanding ELF 符号审计。
- v0.0 空镜像硬件基线及错误尺寸失败路径。
- v0.1 ROM 布局审计。
- QEMU 正常复位与串口成功路径。
- QEMU 串口有界超时失败路径。
- Python 工具单元测试。
- 256 组错误复位目标随机测试。
- LaTeX 书稿输入图检查。

成功路径的真实串口证据：

```text
[OS][FIRMWARE] RESET
[OS][FIRMWARE] SERIAL_READY
```

## 教材

`books/x86-64-os-from-reset/` 已重构为 5 部 10 个完整主题章，覆盖上电、时钟、
复位、x86 历史、数据表示、Intel 汇编、工具链、freestanding C++20、
源码走读、UART、测试以及后续内核机制。各章按状态模型、历史约束、实现机制、
失败路径与验证证据展开，已用 XeLaTeX 编译为 91 页 PDF。

教材构建会自动统计真实目标代码。当前共有 3 个生产源文件、309 个物理行，
其中 231 行为非空、非纯注释代码：C++20 为 94 行，NASM Intel 汇编为
137 行。测试、工具、书籍、网站、构建描述与链接脚本均排除。

## 已知边界

- 固件完成后停机，尚不读取磁盘。
- 尚未启用 A20、GDT、保护模式、分页或长模式。
- 串口使用轮询，不处理中断或接收。
- ROM 失败路径当前由宿主根据缺失标记判断。
