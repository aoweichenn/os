# v2.20 rootfs v5/ext4-mini 生产根切换与 V2 收口

状态：工程候选，V2 实现范围完成；尚未创建公开 tag

日期：2026-08-24

## 完成范围

- 生产启动盘由 rootfs v4 切换为自研 `OSRFV005`；
- 4 KiB block、1024 group、256-byte inode、group bitmap 与动态 CRC32C 计数接入 mount；
- extent leaf、空洞、变长目录、硬链接、符号链接、rename、truncate 与 orphan recovery 接入 VFS；
- journal v2 ordered commit、production commit+checkpoint 和 crash replay 接入真实块设备；
- ATA PIO 增加最多 8-sector READ/WRITE SECTORS 请求，v5 block 只挂起一次；
- mkfs、installer、完整 fsck、v4→v5 copy migration 和稀疏故障盘 clone；
- release identity 与 QEMU 必需 marker 更新为 rootfs format 5；v4 只保留兼容回归。

## 已知边界

- 不兼容 Linux ext4 magic/盘面，不支持 Linux mount；
- metadata transaction 仍由 rootfs 实例锁串行；
- HTree、xattr、ACL 和 quota 的盘面/策略模型属于 V2，但通用用户 ABI 留待后续阶段；
- ext4 的 flex_bg、bigalloc、inline data、fscrypt、verity、DAX、resize、reflink、快照、压缩、
  去重和多设备继续不在 V2。
