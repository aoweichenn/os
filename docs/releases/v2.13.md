# v2.13 目录句柄与 `*at` 路径事务

状态：六个增量已完成，工程候选，尚未发布

日期：2026-08-24

## 目标与六个增量

1. 建立 retain/release `DirectoryHandle` 与统一 `ResolveAt` 基准语义；
2. 完成单目录 `openat/open-directory-at/mkdirat/removeat/statat/readlinkat` VFS 路径；
3. 把 namespace writer 从首次解析到提交串行化，并以 expected sequence 复验；
4. 冻结 ABI v2.5.0 的 88..93、请求布局、flag mask 和用户复制失败边界；
5. 完成双 parent `renameat/linkat` 与 `symlinkat`，保持目录 rename 后旧 fd 身份；
6. 完成同名并发、目录 fd 生命周期、真实 rootfs、VGA、资源和全量回归矩阵。

## 完成范围

- 绝对路径忽略 `dirfd`，`UINT64_MAX` 表示 cwd，其他相对路径只接受目录 FileDescription；
- 每次系统调用短期 retain 目录 vnode，调用结束 release；fd close/duplicate/fork 不暴露裸
  payload，VFS 统计 retain、release、active、peak 与 `*at` 操作总数；
- 目录被 rename 后，旧句柄仍从相同 vnode 解析；source/destination 可使用不同目录 fd；
- create/mkdir/remove/rename/link/symlink/mount 从解析前持有单写锁，提交前复验偶数 namespace
  sequence；并发同名 create 的败者复用锁内二次解析结果，不重入 writer；
- `fs_probe` 在 payload 与后续 metadata mutation 后分别建立持久化屏障；RootFS block scratch
  从调用栈迁入串行实例，reclaim 规划/worker 后处理与 I/O 分段，保持 16 KiB 双 guard 规格；
- ABI v2.5.0 保留 1..87，在末尾追加 88 `OpenFileAt`、89 `OpenDirectoryAt`、90
  `CreateDirectoryAt`、91 `RemoveAt`、92 `StatAt`、93 `ReadSymbolicLinkAt`、94 `RenameAt`、
  95 `LinkAt`、96 `CreateSymbolicLinkAt`；错误区间仍为 -1..-59；
- rootfs v4、4 GiB RAM、128 GiB 磁盘、ATA/NVMe 与 VGA 协议不变；不增加网络、SMP、图形
  或逐路径日志。

## 已知边界

- 当前仍为单 BSP、单 namespace writer；静态双路径 scratch 依赖抢占关闭，不宣称 SMP；
- `StatAt` 只提供 no-follow，`RemoveAt` 只提供 directory 标志；未实现 `openat2`、
  `renameat2`、empty-path、路径能力沙箱或 mount namespace；
- VFS `LinkAt` 沿用现有 link 最终符号链接解析语义，不宣称完整 Linux flag 矩阵；
- 本阶段只形成工程候选，不创建 `v2.13` tag，不执行网站、教材或公共 v2 发布闭环。
