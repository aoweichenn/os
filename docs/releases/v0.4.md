# v0.4：ELF64 内核装载与 BootInfo 交接

发布日期：2026-07-24

## 交付结果

本阶段完成从自研 Stage 1 到 freestanding C++20 内核的第一次真实控制权交接。
QEMU 只模拟 x86-64 CPU、RAM、串口和 IDE；描述符解析、ATA PIO、CRC32、
ELF64 验证、段复制、BSS 清零、BootInfo 构造和入口调用均由项目代码实现。

## 核心能力

- 在长模式下有界读取 Kernel 描述符和最多 512 KiB 的 ELF 文件。
- 独立验证描述符 CRC32、精确负载 CRC32和扇区零填充。
- 两遍解析最多 64 个程序头，验证加载窗口、4 KiB 对齐、权限、W^X、
  段间不重叠与可执行入口。
- 把三个实际 `PT_LOAD` 复制到 `0x00100000` 起的目标区并清零 BSS。
- 建立低 64 MiB 恒等映射和独立的 64 KiB 内核初始栈。
- 通过 RDI 交接 80 字节、固定宽度、版本化 BootInfo。
- 内核独立初始化 COM1，验证 BootInfo、BSS 和 CR3 后进入 `READY`。

## 验收结果

`python3 tools/os.py verify` 共运行 32 项 CTest，覆盖：

- C++ 与 Python 单元测试。
- ELF、磁盘、内存布局和真实产物集成测试。
- 固定种子随机 ELF 标识、地址、长度、负载和补零破坏。
- 从复位向量到内核 `READY` 的 QEMU 系统测试。
- 固件、Stage 1 和 Kernel 的超时、设备错误、头损坏、校验损坏与语义非法
  ELF 失败路径。

成功链路的最终证据：

```text
[OS][STAGE1] KERNEL_HEADER_VALID
[OS][STAGE1] KERNEL_PAYLOAD_VALID
[OS][STAGE1] KERNEL_ELF_VALID
[OS][STAGE1] KERNEL_SEGMENTS_LOADED
[OS][STAGE1] BOOT_INFO_READY
[OS][STAGE1] KERNEL_TRANSFER
[OS][KERNEL] ENTERED
[OS][KERNEL] BOOT_INFO_VALID
[OS][KERNEL] BSS_ZEROED
[OS][KERNEL] CR3_VALID
[OS][KERNEL] READY
```
