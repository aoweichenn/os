# v1.0：交互式用户环境与统一描述符

## 阶段目标

v1.0 把此前分散的控制台、管道和文件能力收束为可由普通 Ring 3 程序使用的
用户环境。完成标准不是“打印一个提示符”，而是外部按键必须经过真实 PS/2
中断唤醒阻塞 Shell，Shell 必须通过统一描述符操作标准 I/O、文件和目录，
系统在无 Ready 进程时必须安全空闲，最后仍通过全部启动、异常和持久化回归。

## 完成内容

- 每个 PCB 建立八槽描述符表，fd 0/1/2 为标准输入、输出、错误，fd 3..7
  承载文件、目录或管道端点。
- 系统调用编号 16..22 增加通用 TryRead/TryWrite、可读/可写等待、通用
  Close、OpenDirectory 与 ReadDirectory；第四参数经 R10 传递。
- 普通文件和管道验收程序迁移到统一读写/关闭路径；历史专用编号保留兼容，
  不再作为正常用户环境主路径。
- PS/2 Set 1 解码扩展为完整 US 基础键区，维护左右 Shift 与 Caps Lock，
  正确区分字母和标点修饰语义。
- 新增 256 字节控制台 FIFO，统计提交、读取、丢弃和残留；IRQ1 只提交字符
  与唤醒，不逐键刷串口。
- 调度器支持最后一个 Running 进程阻塞。没有 Ready 但仍有 Blocked 时返回
  永久内核上下文执行同一汇编块中的 `sti; hlt; cli`，中断后重新派发。
- 新增独立 freestanding Shell ELF、用户态 `memset/memcpy` 最小运行时和
  无分配解析器。
- Shell 提供 help、echo、pwd、ls、mkdir、write、cat、sync、exit；支持
  引号、转义、退格、超长行和未知命令失败语义。
- 文件系统新增目录打开与迭代，固定 64 字节目录项 ABI 保持 inode、类型和
  40 字节名称显式布局。
- QEMU 驱动在 Shell READY 后通过 QMP sendkey 逐字输入十条命令，所有字节
  仍由来宾 i8042/IRQ1/解码器处理；正常日志继续附带宿主单调时间。

## 关键工程发现

新增描述符表最初使用带类内数组初始化的隐式构造。Clang 为全局 PCB 数组生成
了 `.init_array`，而自研启动代码没有也不应偷偷运行 hosted C++ 动态初始化。
Kernel ELF 审计在磁盘生成前拒绝了产物。最终让描述符表保持平凡构造，并由
`Initialize()` 在首次读取前完整覆盖槽位；审计确认 `.init_array` 消失。

第一次整机 Shell 回归完整执行了全部命令，却被内核的旧管道阻塞统计判为失败。
原因是统一 DescriptorReadable/Writable 等待没有计入管道专属统计。修复把
“即将因底层管道条件阻塞”的事件归入同一管道统计，保留历史验收不变量。
这两个问题分别由产物审计和目标内自检发现，说明构建成功与表面交互成功都不是
充分证据。

收口走读还发现，最初的空闲路径分别调用 `EnableInterrupts()` 与
`WaitForInterrupt()`，最终指令可能被 `RET/CALL` 分隔，不能依赖 STI 的紧邻
中断影子。实现改为单一内联汇编块中的 `STI/HLT/CLI`，Kernel ELF 审计直接
解析反汇编并固定三条指令的相邻关系。

## 测试证据

- 控制台 FIFO 和描述符表单元测试覆盖容量、权限、回绕、关闭与统计。
- 键盘单元/随机测试覆盖 make/break、扩展键、Shift、Caps Lock、字母、空格
  和标点。
- Shell 解析器单元测试覆盖普通参数、单双引号、转义、空行和所有显式错误。
- 4096 轮固定种子随机测试既逐字节验证安全参数往返，也生成任意 7-bit 输入，
  检查固定存储边界、失败原子性和重复解析一致性。
- 文件系统生命周期集成测试通过真实目录句柄读取重挂载后的目录项并识别 EOF。
- 调度单元测试证明最后一个进程可 Blocked、NoReady 不等于完成、唤醒后可恢复。
- 正常 QEMU 逐字输入 109 字节，执行十条命令；目标统计要求
  submitted=read=109、dropped=buffered=0。
- 同盘两次全新 QEMU 继续执行 Shell 与文件回归；第三次损坏超级块仍在 Ring 3
  前停止。
- 完整回归共 73 项 CTest，包含单元、集成、固定种子随机、ELF/镜像审计、
  QEMU 成功路径和全部历史失败路径。

## 可观测性

Shell 每条已识别命令输出一个稳定 `COMMAND=...` 标记，未知命令与退出各输出
一个稳定边界。键盘热路径和描述符 Try/Wait 不打印。进程全部结束后才汇总
控制台、管道、文件和调度统计；QEMU 捕获器为每行附加宿主相对毫秒，但来宾
可信时间仍来自 PIT tick 与单调毫秒汇总。

## 已知限制

- 没有 fork/exec/wait、作业控制、信号、管道语法或重定向；
- cwd 固定为根，只接受文件系统当前支持的绝对路径；
- 描述符固定八槽，没有 dup、引用计数、继承与 close-on-exec；
- 终端只有单字节 ASCII 与最小行编辑，没有 Unicode、历史、光标移动或
  canonical/raw 模式；
- 目录只有打开、迭代与关闭，没有删除、rename 或并发修改快照语义；
- 历史专用管道/文件读写系统调用仍保留，后续 ABI 大版本再移除。
