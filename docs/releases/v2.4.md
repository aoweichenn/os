# v2.4 本地身份、安全与资源边界

状态：本地候选完成，待 caw 与手机发布闭环

日期：2026-08-18

## 目标

在不引入网络身份、密码服务或外部文件系统的前提下，为 v2.3 rootfs v4 增加
Linux 兼容的本地 UID/GID、mode、umask、访问检查、凭据继承和资源限制。

## 当前实现

- real/effective/saved UID/GID、32 项 Kernel 补充组、root=0、默认 umask 0022；
- Linux mode 位值、逐级目录 search、父目录 write+search、sticky、setgid 继承、
  root execute 例外及 open 后权限冻结；
- fork/spawn/exec 凭据、umask、组和 rlimit 继承，setuid/setgid exec；
- rootfs v4 `UNIX_METADATA` required feature 与 inode uid/gid/mode 持久化；
- Linux 编号 0..15 的 rlimit ABI；实际约束 FSIZE、DATA、STACK、NPROC、NOFILE、
  AS，CORE 固定为 0；
- `/proc` root:root 0555/0444，`/dev` root:root 0755、字符设备 root:tty 0660；
- ABI v2.3.0、84 个系统调用、112 字节 FileInformation；
- chmod、chown、ln、readlink、真实 id/stat 输出和 Shell builtin umask；rootfs 独立
  工具路径从 43 增至 47。

- 最终统一 CTest：185/185 通过，0 失败，总墙钟 772.49 秒；
- 55 项 unit、68 项 integration、38 项 randomized、24 项 system 全部通过；
- 23 条 failure-path 全部通过；
- 64 MiB bootstrap 41.24 秒、256 MiB functional 104.39 秒、32 GiB 主规格
  127.29 秒、双启动持久化/损坏拒绝 190.63 秒；
- 10 万步 VFS/rootfs 命名空间随机模型 147.11 秒通过；
- functional QEMU 精确创建/退出/收集 183 个 Process，并真实观察安全探针三条
  生命周期标记与 `permission-tools-ready`；
- 两个新增安全 ELF 分别通过段权限、入口、未解析符号和运行时依赖审计；
- Python rootfs v4 mkfs/install/inspect/fsck 与末 LBA 测试通过；基础镜像
  70 个可达 inode、67 个普通文件，fsck 无 orphan；
- Kernel payload 1779176 字节，RW `MemSiz=0x5edc38`；128 GiB 镜像逻辑长度
  137438953472 字节，当前宿主物理占用约 25 MiB。

最终统一轮次之前，连续重建压力下曾各观察一次 64 MiB ATA 首读
`DeviceFailure` 和一次既有 Shell child 退出后的 wait 进度丢失；两档不改代码、
不放宽门禁原样重跑均通过，随后第三轮统一 185 项全部通过。本页只把第三轮作为
完成证据，保留前两次轨迹作为后续长稳分析输入。

## 已知边界

- ABI 保留 Linux `NGROUPS_MAX=65536`，当前 Kernel 固定容量为每进程 32 项；
- CPU/RSS/LOCKS/SIGPENDING/MSGQUEUE/NICE/RTPRIO/RTTIME 的编号稳定，但缺少对应
  子系统时不宣称已执行限制；
- 没有 passwd/group 数据库、登录、ACL、capabilities、LSM、user namespace 或网络；
- caw 当前仍不可达，本页不宣称远端、手机或正式发布闭环完成。
