# v2.2：终端、Shell 与本地命令环境

状态：本地候选完成，待 caw 隔离验证、手机交互证据与正式发布动作

## 能力

- 512 字节行内左右插入、16 条历史、Tab 命令补全；外部作业保持 canonical；
- `;`、`&&`、`||`、16 级管线、`<`、`>`、`>>`、`2>`、`2>>` 与后台作业；
- 32 项环境、赋值、export/unset、`$NAME`、`${NAME}`、`$?`、exec 继承；
- 引用感知 `*`/`?` glob，匹配排序并保持每 stage 8 参数边界；
- 43 个独立工具 inode，新增 err/env/grep/find/sort/tail/df/du/hexdump/clear/date；
- ABI v2.1.0 的受控输入模式和 CMOS RTC UTC，既有 1..69 保持兼容。

## 本地证据

- 单元：Terminal 模式、VGA CSI、环境、glob、行编辑、RTC 日历；
- 随机：4096 组 Shell 解析、10000 步环境、10000 组 glob oracle、20000 步编辑；
- QEMU functional：真实 Left/Up/Tab、环境/glob、全部控制与重定向、新增工具、
  CMOS UTC、43 inode、95 个 Shell child 与完整资源回收。
