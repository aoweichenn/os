# v2.19 变长目录、HTree、inode extension、xattr、ACL 与 quota

状态：工程候选，尚未发布；v2.20 生产切换未完成

日期：2026-08-24

## 完成范围

- 4 KiB variable dirent block、CRC32C 和 UUID/inode generation binding；
- 8 路 HTree，最多 512 entry、73 node、深度 2，hash collision 逐名称确认；
- 128 字节 inode extension v1 与 feature/pointer/generation fail-closed 验证；
- sorted xattr set/block、四类 namespace、16 entry、256-byte value；
- POSIX ACL owner/named/group/mask/other permission evaluation；
- 48-record user/group quota、hard/soft/grace 和 usage rollback；
- 十万步 directory/xattr/quota oracle。

## 验证证据

- CAW 聚焦测试 3/3、0 失败：directory unit、metadata unit/failure、randomized；0.03 秒；
- fresh CAW 工具链为 Python 3.13.9、Clang/LLD 21.1.8、NASM 2.16.03、QEMU 10.1.5；
  Debug 全构建 3745 个目标，零警告；
- `python3 tools/os.py verify` 为 267/267、0 失败：83 unit、90 integration、61 randomized、
  33 system，含 29 failure-path；CTest 857.28 秒，后台墙钟约 930 秒，峰值宿主内存 6.5 GiB；
- 4 GiB ATA/NVMe primary 为 69.55/68.00 秒，reclaim 为 74.24/78.46 秒，OOM 为
  76.71/76.41 秒，三启动 persistence 为 138.06/137.48 秒；NVMe normal/EIO/timeout 为
  2.68/2.63/10.18 秒；
- 这些 system 结果仍使用 rootfs v4，只证明 v2.19 没有回归，不能作为 v2.20 生产切换证据。

## 已知边界

- v5 production backend、迁移、完整 fsck 和 mount 尚未完成；
- directory/xattr/quota block 尚未由真实 inode extent 引用；
- xattr 不实现 EA inode/共享值，quota 没有并发 transaction reservation；
- 本记录不能作为“整个 V2 已完成”的证据。
