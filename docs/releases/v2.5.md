# v2.5 4 GiB 实体内存与 28 GiB 交换盘

状态：caw 候选验证完成，待手机运行与正式发布闭环

日期：2026-08-20

## 目标

让手机来宾实际使用 4 GiB 客体 RAM，并以 28 GiB 独立交换数据提供约 32 GiB
可分页容量；把 file page cache、匿名页、swap、overcommit、OOM 和进程退出接成
可失败、可回滚、可观测的恢复路径。

## 当前实现

- 单 Normal 域 min/low/high 水位；4 GiB 参考机由 QEMU `-mem-prealloc` 实际提交；
- clean file page 裁剪返回真实回收页数，用户 demand fault/COW 分配接入回收；
- secondary IDE master 上的 `OSSWAP01` 原始交换盘，7340032 个 4 KiB 数据槽；
- 每槽 64 字节磁盘哈希元数据与独立元数据校验，数据先于元数据 flush；
- 匿名、program-break、用户栈换出/换入，fork clone 与 unmap/exec/exit 回收；
- Linux 编号 overcommit 0/1/2，默认 heuristic，严格模式 swap + 50% RAM；
- 匿名 mmap、brk、fork、失败回滚和地址空间销毁的 commit 守恒；
- resident+swap OOM 分数、PID 1 保护、确定性平分和非当前 Process 终止；
- `/proc/meminfo` 暴露驻留预算、swap、commit limit 与 OOM kill；
- 启动阶段用 secondary ATA PIO 对 swap 槽执行 4 KiB 写入、读回、校验和释放；
- 工程镜像与手机运行镜像分离；后者必须通过 `posix_fallocate` 和 `st_blocks` 门禁；
- 项目版本与 Shell/Kernel banner 更新为 2.5.0/v2.5，ABI 继续保持 v2.3.0。

## 已知边界

- swap 数据固定 28 GiB，不支持动态 swapon、休眠恢复、zswap 或 readahead；
- COW 页在仍共享时不换出；fork 对已换出独占页复制槽；
- 无 NUMA、SMP reclaim worker、THP、mlock、memory cgroup 或可写 VM sysctl；
- 4 GiB RAM 持续换页时性能受手机闪存限制；QEMU 进程还有客体 RAM 之外的开销；
- 当前声明 caw 全量工程候选，不宣称手机运行或正式公开发布完成。
