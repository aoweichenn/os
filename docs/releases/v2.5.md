# v2.5 32 GiB 内存压力与恢复

状态：本地候选完成，待 caw 与正式发布闭环

日期：2026-08-20

## 目标

让 32 GiB 来宾在内存较小的手机宿主上维持有界 RSS，并把 file page cache、
匿名页、swap、overcommit、OOM 和进程退出接成可失败、可回滚、可观测的恢复路径。

## 当前实现

- 单 Normal 域 min/low/high 水位；32 GiB 参考机使用 4 GiB 已触碰驻留预算；
- clean file page 裁剪返回真实回收页数，用户 demand fault/COW 分配接入回收；
- root:root 0600 的 256 MiB 稀疏 `/.os-swap`，65536 个 4 KiB 校验槽；
- 匿名、program-break、用户栈换出/换入，fork clone 与 unmap/exec/exit 回收；
- Linux 编号 overcommit 0/1/2，默认 heuristic，严格模式 swap + 50% RAM；
- 匿名 mmap、brk、fork、失败回滚和地址空间销毁的 commit 守恒；
- resident+swap OOM 分数、PID 1 保护、确定性平分和非当前 Process 终止；
- `/proc/meminfo` 暴露驻留预算、swap、commit limit 与 OOM kill；
- 启动阶段用真实 VFS 对 swap 槽执行 4 KiB 写入、读回、校验和释放；
- 项目版本与 Shell/Kernel banner 更新为 2.5.0/v2.5，ABI 继续保持 v2.3.0。

## 本地证据

- memory pressure、swap manager 各自的 unit/randomized 目标通过；随机模型分别
  执行 100000 步，OOM 另执行 4096×32 候选 oracle；
- file page cache、ThreadScheduler、procfs 的相关 unit/integration/randomized
  回归通过；QEMU tooling 33 项通过；
- freestanding 主 Kernel 及全部故障变体零警告链接，目标 ELF 审计通过；
- 64 MiB 调试运行已观察 swap 初始化通过并进入完整用户流程；路径长度包含 NUL
  的首次失败由 `SWAP_INITIALIZATION_STAGE=1` 定位并修复；
- functional 曾在 procfs 回调按值构造完整 ProcessRuntimeStatistics，16 KiB
  KernelStack 越过 guard 后由 PIT 入栈触发 #DF；已改用轻量 observation snapshot；
- 32 GiB/persistence 压力曾在 FsContext 目录 close 重读 root inode 时遇到 ATA
  `DeviceFailure`；目录持有引用时不可删除/复用，现按该不变量无 I/O 释放并有
  故障注入集成测试；
- 最终串行 CTest：188/188 通过，0 失败，总墙钟 709.34 秒；57 unit、67
  integration、40 randomized、24 system，含 23 条 failure-path；
- 64 MiB bootstrap 27.27 秒、256 MiB functional 70.58 秒、32 GiB 主规格
  120.03 秒、双启动持久化与损坏拒绝 189.32 秒；
- 单独采样的 32 GiB 主规格宿主峰值 RSS 为 95976 KiB，同时实际触及
  `0x800000000` 高物理地址并完成写回/回收；
- 最终强 marker 证明 committed=0、active swap=0、swap checksum failure=0；
  启动自检至少完成一次真实 store/load，所有 Process/VMA/COW/KernelStack 守恒；
- Kernel payload 1813968 字节，RW `MemSiz=0x7f5f58`；128 GiB 启动盘逻辑长度
  137438953472 字节、宿主物理占用约 25 MiB；
- rootfs v4 fsck：70 个可达 inode、3 个目录、67 个普通文件、无 orphan。

## 已知边界

- swap 固定 256 MiB，不支持动态 swapon、休眠恢复、zswap 或 readahead；
- COW 页在仍共享时不换出；fork 对已换出独占页复制槽；
- 无 NUMA、SMP reclaim worker、THP、mlock、memory cgroup 或可写 VM sysctl；
- caw 当前仍不可达，本页不宣称远端或正式发布完成。
