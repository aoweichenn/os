# v2.12 可扩展、页后备 VFS 命名空间

状态：六个增量已完成，工程候选，尚未发布

日期：2026-08-23

## 目标与六个增量

1. 用分片 `RuntimeMutex` 建立 dentry lookup waiter 协调；
2. 删除生产 path walk 的全局 resolution 串行，加入 128 个独立解析上下文；
3. 用偶/奇 namespace sequence 关闭 rename/unlink/create/mount 与 resolver 的可见性窗口；
4. 把 namespace slot、index、bucket 和 scratch 迁移到真实内核页 backing；
5. 支持在线 hash rebuild、compact tier 和 preferred 页真实释放；
6. 完成同 key/不同 shard、metadata、mutation retry、溢出、压力与资源故障矩阵。

## 完成范围

- dentry 与 inode metadata 各 64 个 waitable shard；多 inode 写操作统一升序锁序；
- 128 个 8 KiB 解析 scratch context，峰值进入 VFS 聚合统计；
- mutation sequence 有界八次重试，跨提交的缓存结果不会返回调用者；
- 4096 dentry、2048 inode 仍保持真实固定规格，但 backing 不再是 BSS：稳定区和 preferred
  hash 区都由 `AllocateKernelPages` 分配并记录完整 frame/KVA 资源差值；
- pressure 首批从 8192/4096 bucket 重建为 4096/2048，并用 `ReleaseKernelPages` 归还 preferred
  区；稳定区继续持有 slot、entry、compact bucket 和解析上下文；
- 用户 resident pressure 显式排除不可回收 namespace 页，释放 preferred 层时同步减少排除数，
  既有 9216 页 reclaim profile 无需放宽；
- ABI 2.4.0、rootfs v4、4 GiB RAM、128 GiB 磁盘、ATA/NVMe 与 VGA 终端协议不变；不增加
  网络、SMP、图形或逐项日志。

  QMP VGA 可见画面。

## 已知边界

- 当前仍是单 BSP；64 shard 解决逻辑并发和未来扩展锁序，不宣称 SMP/RCU；
- namespace mutation 仍为单写事务，slot 容量仍固定；压力只释放 preferred hash 页，稳定
  slot/context 页必须保留到 VFS teardown；
- 本阶段只形成工程候选，不创建 `v2.12` tag，不执行网站、教材或公共 v2 发布闭环。
