# v2.10 异步块 I/O 与可等待页缓存

状态：前两增量和第三增量 3a 已完成，工程候选，尚未发布

日期：2026-08-23

## 目标

把现有控制器请求模型接入设备无关的异步提交、完成和等待路径，再让同页 cache miss、
预读、writeback 与 reclaim 使用同一可睡眠 I/O 生命周期。rootfs v4、ABI 2.4.0、ATA
回退和 4 GiB 手机参考机保持不变。

## 增量顺序

1. `BlockRequestQueue` 有序 completion FIFO 与 owner 交付（已完成）；
2. 异步 `BlockDevice` adapter，统一 ATA/NVMe submit/cancel/timeout/completion（已完成）；
3. `BlockIo` WaitQueue 与生产 rootfs/swap 迁移：3a 协调器/Worker/Kernel 等待已完成，
   3b 浅层 I/O 委托、锁拆分和生产迁移待完成；
4. FilePageCache Loading waiter、同页 miss 合并与失败广播；
5. 顺序读预读窗口、命中/浪费反馈与内存压力收缩；
6. 并发 writeback/reclaim、取消、EIO/timeout 和 ATA/NVMe 持久化矩阵。

## 第一增量范围

- Completed 请求按解析发生顺序进入独立有界 FIFO；
- `BlockCompletion` 冻结 request id、操作、范围、owner 和终态结果；
- `TakeCompletion` 原子交付并回收，空队列明确返回 unavailable；
- 直接 Reap 可以摘除 FIFO 中间项，其余顺序保持不变；
- ATA IRQ/timeout 改用统一完成出口；
- 单元、集成和十万步随机 oracle 同时覆盖 IRQ、timeout、cancel、直接回收与完成交付；
- 不迁移 rootfs，不增加系统调用，不改变磁盘格式。

## 当前边界

- 同步 `BlockDevice::ReadBlock/WriteBlock/Flush` 仍是 rootfs、journal 和 swap 生产入口；
- NVMe probe 自检已走异步 adapter，生产 rootfs/swap 仍在驱动内同步等待；
- FilePageCache Loading 冲突仍返回 Busy，没有 WaitQueue waiter；
- BlockIo bottom-half/WaitQueue 已由第三增量建立；生产 rootfs/swap 迁移和可等待页缓存仍
  不在本次完成声明内。

## 第二增量范围

- 新增无 virtual/RTTI/分配的 `AsynchronousBlockDevice` 静态适配层；
- ATA 系统调用 submit、timer timeout、IRQ14 completion 通过公共接口；
- NVMe namespace 使用 64 位 request id 映射 16 位 CID，完成按 CQ 顺序交付；
- NVMe IRQ 不复制 Read 数据，非 IRQ TakeCompletion 回拷 DMA 页并释放 slot；
- timeout reset 保留已有完成，并把最早到期/其余未完成分别交付 TimedOut/DeviceError；
- cancel 冻结 best-effort 语义，不伪造已签发硬件请求被撤销；
- 不迁移 rootfs、journal、swap，不改变 ABI 2.4.0 或 rootfs v4。

## 第三增量基础范围

- 新增 64 槽 `BlockIoCoordinator`，用 owner、request id 和 generation ticket 表达
  Registered/Waiting/Completed/Abandoned 生命周期；
- completion-before-wait 直接取结果，wait-before-completion 精确唤醒，迟到 abandoned
  completion 只回收身份；
- 常驻 completion Kernel Thread 在非 IRQ 上消费已登记设备，IRQ/timer 只增加通知
  generation；worker 睡前复核 generation，关闭扫描与阻塞间的丢通知窗口；
- `AwaitRuntimeBlockIo` 只允许 Kernel Thread 使用；请求接受后的协议损坏采用 fail-stop，
  防止设备继续访问已经展开的 caller buffer；
- secondary ATA Flush probe 真实通过 IRQ15 完成，primary root 与 secondary swap 状态机分离；
- rootfs/swap `BlockIoDevice` 保持 async 开关关闭，生产操作统计必须为零；
- 用户地址空间销毁记录精确阶段、映射状态、文件后备 close 状态，失败不再只报告笼统
  `AddressSpaceFailure`；
- 不改变 rootfs v4、ABI 2.4.0、磁盘容量或 4 GiB 主规格。
