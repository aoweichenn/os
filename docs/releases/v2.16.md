# v2.16 rootfs v5 block-group 盘面基础

状态：六个增量已完成，工程候选，尚未发布

日期：2026-08-24

## 目标与六个增量

1. 冻结 4 KiB block、128 MiB group、256 字节 descriptor/inode 和 inode profile；
2. 实现 freestanding superblock、group descriptor、inode 与 CRC32C 编解码；
3. 实现 feature、算术、组边界、尾组、稀疏备份和保留区 fail-closed 验证；
4. 实现独立 mkfs/inspect/fsck/corrupt 与 128 GiB、小几何双 profile；
5. 完成固定向量、十万步随机和十类盘面损坏测试；
6. 完成文档、全构建、rootfs v4 整机回归和 fresh CAW 验证。

## 完成范围

- 新增 `root_file_system_v5_format.*`，以固定宽度字段和显式小端读写定义 `OSRFV005`；
- 参考几何为 33550336 个 4 KiB 块、1024 个 128 MiB group、2097152 个 256 字节 inode；
- primary GDT 占 64 块；15 个 sparse copy group 保存一致的 superblock 与完整 GDT；
- 每组有独立 block/inode bitmap 和 inode table，尾组按真实容量缩短；inode 1..15 预留，
  inode 2 为 0755 根目录；
- superblock、descriptor、inode 和 bitmap 使用 CRC32C；未知/缺失 required feature、错误几何、
  非零保留区、重叠和备份分歧全部拒绝；
- 新增 `mkfs-rootfs-v5`、`inspect-rootfs-v5`、`fsck-rootfs-v5`、`corrupt-rootfs-v5`，覆盖
  安全创建、显式强制覆盖、JSON 摘要和十类确定性损坏；
- v5 仍是实验格式，生产 rootfs v4、启动镜像、ABI、QEMU 与手机运行路径不变。

## 验证证据

- CAW Python 工具测试 4/4：生产几何与 CRC、small-image 往返/备份/bitmap/覆盖安全、feature
  协商，以及十类损坏逐项拒绝；
- C++ 新增 unit/randomized 2/2，其中 randomized 固定种子 `0x524F4F5456354752` 执行十万次；
- 固定 profile 的 C++/Python superblock checksum 同为 `0x9B5E7B2E`；
- fresh CAW 工具链为 Python 3.13.9、Clang/LLD 21.1.8、NASM 2.16.03、QEMU 10.1.5、
  CMake 3.31.11 与 Ninja 1.13.1；Debug 全构建完成 3476 个目标，零编译警告；
- `python3 tools/os.py verify` 为 254/254、0 失败：77 unit、86 integration、58 randomized、
  33 system，含 25 条 failure-path；CTest 784.45 秒，后台任务墙钟约 921 秒，CAW 峰值宿主
  内存 6.4 GiB；
- 4 GiB ATA primary 为 65.21 秒，NVMe storage primary 为 63.65 秒；ATA/NVMe reclaim 为
  66.59/68.34 秒，OOM 为 68.41/68.28 秒；ATA/NVMe 三启动 persistence 为 127.73/128.98 秒；
  NVMe normal/EIO/timeout 为 2.34/2.29/9.77 秒；
- system profile 继续从 reset vector 进入自研启动链，使用生产 rootfs v4，并要求 QMP
  screendump 可见、资源守恒与零禁止 marker；v5 没有借这些结果冒充生产挂载。

## 已知边界

- 没有 v5 mount、目录项、普通文件数据、extent、allocator 或 journal；这些从 v2.17 起推进；
- 当前 fsck 只验证新格式空镜像的精确初始状态，不是 v2.20 的完整可达性检查器；
- `--create` 生成的 128 GiB 实验镜像可保持宿主稀疏；它不是手机运行盘，不能绕过生产镜像
  物化规则；
- 本阶段不创建 `v2.16` tag，不覆盖独立在制书稿，也不启动网站/Sites 发布闭环。
