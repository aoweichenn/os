# v0.3：Long Mode

## 交付范围

- Stage 1 自行打开并验证 A20。
- 建立基址为零的平坦 GDT，并进入 32 位保护模式。
- 在独立物理页中建立 PML4、PDPT 和 PD，以 2 MiB 大页身份映射低地址。
- 回读验证 `CR3`、`CR4.PAE`、`IA32_EFER.LME`、`CR0.PG` 和
  `IA32_EFER.LMA`。
- 通过 L 位代码段远跳进入 64 位子模式。
- 16、32 和 64 位阶段各自使用适合当前译码模式的串口发送路径。

## 启动证据

成功路径最终依次输出：

```text
A20_READY
GDT_READY
PROTECTED_MODE
PAGE_TABLES_READY
PAE_READY
LME_READY
PAGING_ENABLED
LONG_MODE
```

页表、PAE、LME 与分页各有独立的自检失败标记；QEMU 协议验证要求成功标记
严格有序，并禁止失败标记出现在正常启动中。

## 已知边界

- 当前只映射最低 2 MiB，尚未建立内核高半区。
- 尚未解析或装载 ELF64 内核。
- PIT 已初始化，但来宾 IRQ0 和 PIT 毫秒时间戳要在 IDT 建立后接入。
