# 开发路线

| 版本 | 阶段 | 核心验收目标 |
| --- | --- | --- |
| v0.0 | 工程基线 | 构建、测试、持续集成和文档结构可复现 |
| v0.1 | 复位与串口 | 自定义 ROM 从复位向量输出串口日志 |
| v0.2 | 固件加载 | IDE PIO 正确加载自研 Stage 1 |
| v0.3 | Long Mode | 独立完成 16 位到 32 位再到 64 位切换 |
| v0.4 | 内核加载 | 校验并加载 ELF64 内核，交接 BootInfo |
| v0.5 | 内核基础 | 建立 GDT、IDT、TSS、异常和 panic |
| v0.6 | 内存管理 | 实现物理页、虚拟地址空间和内核堆 |
| v0.7 | 中断与设备 | 驱动 PIC、PIT、键盘和 IDE |
| v0.8 | 用户边界 | 进入 Ring 3，实现用户 ELF 和系统调用 |
| v0.9 | 进程调度 | 实现抢占调度和进程生命周期 |
| v0.10 | 同步与 IPC | 实现锁、睡眠唤醒和管道 |
| v0.11 | 文件系统 | 实现 inode、目录、文件和持久化 |
| v1.0 | 用户环境 | 提供 Shell、基础命令和完整系统回归 |

每个阶段的详细验收项维护在项目门户的 `/roadmap/` 页面；阶段开始前应进一步拆分为可独立验证的任务。
