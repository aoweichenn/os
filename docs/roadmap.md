## v0.1 验收记录

- 128 KiB ROM 精确映射 `0xFFFE0000..0xFFFFFFFF`。
- `0xFFFFFFF0` 复位向量通过 16 位 near jump 进入 `0xFFFFF000`。
- 入口自行建立段寄存器、栈和方向标志状态。
- COM1 自行完成 115200、8N1、FIFO 和 modem control 初始化。
- 发送前轮询 THRE 状态位，最多 `0xFFFF` 次后返回失败。
- 正常镜像输出 `RESET` 与 `SERIAL_READY`。
- 故障注入镜像输出 `RESET`，但必须在超时后停止且不能输出
  `SERIAL_READY`。
- ROM 布局由最终二进制审计，错误位移由 256 组固定种子随机输入验证。
- LaTeX 教材可以独立检查并编译为 PDF。

当前进度：`2 / 13`。下一阶段为 `v0.2 固件加载`。
